Sau [PoC HD-2D](/posts/1.-hd2d-poc/), mình chọn đi tiếp với bản Godot. Có điều mọi thứ vẫn nằm trong code của đúng một cảnh. Mình muốn lần sau chỉ cần mô tả cảnh là agent dựng được một cảnh HD-2D mới, nên đã nhờ agent đóng gói những gì học được thành một agent skill tên `godot-hd2d`.

## Bước 1: chuyển cảnh từ code sang object (19–20/11)

Mình hỏi agent: "ở godot map và các object trên map được tạo ra bằng cách nào?", rồi hỏi tiếp: "với việc sử dụng thực tế nên dùng như vậy luôn hay chuyển thành object 3d?". Agent đề xuất 3 bước và viết thành `GODOT_SCENE_PIPELINE_PLAN.md`. Mình chạy `/goal Hoàn thành @GODOT_SCENE_PIPELINE_PLAN.md`, và agent làm xong mỗi bước bằng một commit:

- `9ba1353`: shader bề mặt tự tính UV theo không gian của vật thể.
- `6389023`: nhà thành prefab `@tool`, kéo thả và đổi tham số được ngay trong editor.
- `fddae29`: địa hình chuyển sang Terrain3D 1.1.0, nắn và tô được trong editor. Trước đó một subagent `scout` đi tra cứu API của Terrain3D.

## Bước 2: prompt tạo skill

```text
Tôi nghĩ rằng việc agent có thể tạo được godot scene là rất tốt. Tôi muốn bạn tạo agent skill vào `/Users/vietlubu/Projects/vietlubu/tools/agents/skills` để sau này có thể dùng lại.
Tôi chưa xác định được tên. cũng chưa biết nên để vào 1 skill hay tách ra nhiều skill. Ngoài character ra thì tôi cần skill đủ thông tin để tạo được object trên map, nhà cửa, cây cối, nước, đất trời, chim, bướm,... quan trọng nhất ánh sáng và phong cách hd2d.
```

Agent đọc skill `writing-for-agents` (hướng dẫn viết tài liệu cho agent) và đọc lại toàn bộ code Godot của PoC, rồi hỏi mình 3 câu:
- **Cấu trúc:** 1 skill, 2 skill, hay nhiều skill theo mảng? Mình chọn 1 skill, mỗi mảng một file reference.
- **Mức code đi kèm:** template chạy được, bộ shader/script, hay chỉ tài liệu? Mình chọn template Godot chạy được.
- **Sau khi tạo:** mình chọn symlink vào `~/.agents/skills` và commit.

Agent viết plan rồi chạy plan đó trong một session mới, mất khoảng 30 phút.

## Trong skill có gì

```text
godot-hd2d/
  SKILL.md                 quy trình dựng cảnh, catalogue prefab, 8 luật HD-2D, lệnh, gotchas
  references/              style, lighting, architecture, terrain-water, vegetation, sky-atmosphere, life
  scripts/new_project.sh   tạo project mới từ template, cài Terrain3D, bake địa hình
  template/                project Godot chạy được: rig ánh sáng/camera/post, shader, prefab @tool
  agents/openai.yaml
```

**Rig** (`hd2d/rig.gd`) là gốc của `main.tscn`. Nó lo:
- camera, mặt trời và mặt trăng;
- sương volumetric, gương nước, DOF tilt-shift, chỉnh màu;
- preset hoàng hôn, đêm và mưa;
- chế độ chụp ảnh và đo FPS.

**Prefab `@tool`** gồm:
- nhà (3 kiểu mái), tường, cầu thang, cầu, đạo cụ;
- cối xay gió, vải bay;
- cây, bụi, hàng cây xa, cỏ;
- ao, thác, núi xa, god rays, đom đóm;
- đàn chim, chim nhảy, bướm, diều;
- sprite nhân vật.

Mỗi prefab tự dựng lại khi đổi tham số, nên editor luôn hiện đúng kết quả. Agent đặt prefab chỉ bằng cách sửa text `main.tscn`.

**8 luật HD-2D** trong `SKILL.md`:
1. 32 texel mỗi unit;
2. lọc nearest, không mipmap;
3. chỉ scale theo số nguyên;
4. dải màu 4 tông lệch hue;
5. FOV hẹp 21°, camera nghiêng 17°;
6. cảnh chia bậc T0–T4;
7. phân tầng sáng tối rõ ràng;
8. hiệu ứng dùng có chừng mực.

## Agent tự kiểm chứng

| Kiểm tra | Kết quả |
|---|---|
| `new_project.sh /tmp/hd2d-check` | `BAKE ok regions=4`, Terrain3D tải về và khớp sha256 |
| Ảnh hoàng hôn / đêm / mưa | log không có lỗi, agent xem từng ảnh |
| Bench | 69.3 fps (bản PoC: 70.3 fps) |
| Mở `main.tscn` trong editor 90 giây | không lỗi |
| Thử dựng cảnh theo `SKILL.md` | thêm cây, cột đèn, bướm: tất cả đứng đúng trên mặt đất, log sạch |

Trong lúc làm, agent ghi thêm vào phần gotchas vài lỗi chỉ gặp khi chạy thật. Ví dụ: trên Godot 4.7, một `GPUParticles3D` tạo bằng code mà có đặt tên sẽ bị leak shader khi thoát.

## Dùng thử

Cần Godot 4.7 (mình dùng 4.7.1 rc2), `curl`, `unzip` và `shasum`. Lần đầu chạy, script sẽ tải Terrain3D 1.1.0 (khoảng 43 MB).

```sh
bash godot-hd2d/scripts/new_project.sh ~/Projects/my-hd2d --name "My HD-2D"
godot --path ~/Projects/my-hd2d
```

Cách mình hay dùng hơn là gõ `/skill:godot-hd2d` trong agent rồi mô tả cảnh muốn dựng. Bài sau, [Lạc Giới #1](/posts/3.-lacrealm-tu-hd2d-poc/), là một ví dụ.
