Trước khi viết về các project HD-2D, mình ghi lại bộ công cụ đang dùng. Các bài sau đều làm trên bộ này.

## MacBook Pro M1 Pro

[MacBook Pro 14 inch (2021)](https://support.apple.com/en-us/111902), chip M1 Pro, RAM 16 GB. Máy đã vài năm tuổi nhưng vẫn chạy được scene Godot Forward+ ở 2560×1440 khoảng 70 fps, trong lúc vài agent chạy song song.

## Herdr

[Herdr](https://herdr.dev/) ([herdr-app trên GitHub](https://github.com/herdrdev/herdr-app)) là app desktop cho terminal và coding agent:
- mỗi project là một space riêng;
- nhìn được agent nào đang chờ mình trả lời;
- đóng cửa sổ thì terminal và agent vẫn chạy tiếp.

Mình dùng nó để chạy nhiều session `omp` cùng lúc.

## omp

[omp](https://omp.sh/) (oh-my-pi, [GitHub](https://github.com/can1357/oh-my-pi)) là coding agent chạy trong terminal. Những thứ mình dùng nhiều nhất:
- `/goal`: giao việc rồi để agent tự chạy đến khi xong;
- subagent: chia việc cho nhiều agent chạy song song, mỗi agent chọn model và mức suy nghĩ riêng;
- skill: quy trình đóng gói sẵn, gọi bằng `/skill:<tên>`;
- MCP: kết nối agent với Blender, Aseprite, Chrome DevTools…;
- plan mode: với việc lớn, agent hỏi lại và viết plan trước khi làm.

## Claude Max 5x

[Claude Max](https://claude.com/pricing), gói 5x ($100/tháng): lượng dùng gấp 5 lần gói Pro, tính theo mỗi 5 giờ và mỗi tuần. Mình dùng gói này cho omp, model chính là Claude Opus 5.5. Chạy nhiều subagent cùng lúc thì vẫn có lúc chạm giới hạn, như ở [bài PoC HD-2D](/posts/1.-hd2d-poc/).

## Godot 4.7

[Godot](https://godotengine.org/) ([tải về](https://godotengine.org/download/)) là game engine mã nguồn mở. Mình dùng bản 4.7.1 rc2 với renderer Forward+, cùng addon [Terrain3D](https://github.com/TokisanGames/Terrain3D) cho địa hình.

Godot hợp để làm việc với agent: scene và script đều là file text, nên agent đọc và sửa trực tiếp được. Agent cũng chạy được Godot từ dòng lệnh để chụp ảnh, đo FPS, hay xuất video bằng Movie Maker.
